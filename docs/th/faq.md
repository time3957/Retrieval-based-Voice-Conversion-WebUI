# คำถามที่พบบ่อย

## 1. เจอข้อผิดพลาดเกี่ยวกับ FFmpeg หรือ UTF-8

มักเกี่ยวกับพาธหรือชื่อไฟล์เสียง ลองย้ายไฟล์และโฟลเดอร์ไปไว้ในพาธสั้น ๆ ที่ใช้อักษรภาษาอังกฤษและตัวเลขก่อน แล้วลองใหม่ โดยเฉพาะตอนเตรียมชุดข้อมูลฝึก

## 2. ฝึกเสร็จแล้วแต่ไม่พบไฟล์ Index

ถ้าหน้าจอแจ้งว่าฝึกเสร็จ โมเดลอาจฝึกสำเร็จแล้ว แต่การสร้าง Index อาจยังไม่เสร็จหรือใช้หน่วยความจำมาก ให้กดปุ่ม **ฝึก Index** อีกครั้ง และตรวจ log ของการทดลอง

## 3. ฝึกโมเดลแล้ว แต่ไม่พบในรายการเสียง

กด **รีเฟรชรายการโมเดลเสียง** ก่อน ตรวจว่าไฟล์โมเดลใช้งาน `.pth` อยู่ใน `assets/weights/` หากยังไม่พบ ให้ตรวจ log ใน `logs/<ชื่อการทดลอง>/`

## 4. ใช้โมเดลของคนอื่นหรือแชร์โมเดลอย่างไร

สำหรับการแปลงเสียง ให้ใช้ไฟล์โมเดล `.pth` ที่สกัดไว้ใน `assets/weights/` และใช้ไฟล์ `.index` ที่เข้าคู่กันจาก `assets/indices/` หากมี ไฟล์ Checkpoint ขนาดใหญ่ใน `logs/` ใช้สำหรับฝึกต่อ ไม่ควรเปลี่ยนชื่อหรือนำไปใช้แทนโมเดล `.pth` โดยตรง

## 5. WebUI แจ้ง Connection Error

ตรวจว่าหน้าต่าง Terminal/Command Prompt ที่รัน WebUI ยังเปิดอยู่หรือไม่ หากปิดหน้าต่างนั้นไป ให้เปิด WebUI ใหม่แล้วเข้า URL ที่แสดงในหน้าต่าง

## 6. พบข้อความ “Expecting value: line 1 column 1 (char 0)” ใน WebUI

ลองปิด Proxy/VPN ของระบบชั่วคราว แล้วรีเฟรชหน้า หากยังเกิดซ้ำ ให้ตรวจข้อความผิดพลาดใน Terminal/Command Prompt

## 7. ใช้งานโดยไม่เปิด WebUI ได้หรือไม่

ทำได้ แต่เหมาะกับผู้ใช้ที่คุ้นเคยกับ Python และบรรทัดคำสั่ง สำหรับการฝึก สามารถเริ่มตั้งค่าจาก WebUI แล้วดูคำสั่งที่แสดงในช่องข้อความได้ ส่วนตัวอย่างสคริปต์ Inference ของโครงการอยู่ที่ [myinfer.py](https://huggingface.co/lj1995/VoiceConversionWebUI/blob/main/myinfer.py)

## 8. CUDA Error หรือหน่วยความจำการ์ดจอไม่พอ

ลด Batch Size ในการฝึก หรือปิดโปรแกรมที่ใช้ GPU อยู่ หากยังไม่พอ อาจต้องใช้การ์ดจอที่มีหน่วยความจำมากขึ้น การแปลงเสียงมีค่าหน่วยความจำใน `configs/config.py` ที่ปรับได้ แต่ควรเปลี่ยนทีละค่า

## 9. ควรตั้งจำนวน Epoch เท่าไร

ไม่มีค่าตายตัว คุณภาพและความยาวของเสียงฝึกมีผลมาก เริ่มจากค่าปานกลางก่อน แล้วฟังผลและตรวจกราฟ/Log การฝึก การเพิ่ม Epoch ไม่ได้ทำให้เสียงดีขึ้นเสมอไป

## 10. ต้องมีเสียงฝึกนานแค่ไหน

คู่มือโครงการเดิมแนะนำประมาณ 10–50 นาที โดยเน้นเสียงสะอาดและโทนสม่ำเสมอ ชุดเสียงที่สั้นกว่านี้อาจทดลองได้ แต่ผลลัพธ์และความเสถียรจะแตกต่างกัน

## 11. Index Rate คืออะไร และควรปรับอย่างไร

เป็นสัดส่วนการอ้างอิงคุณลักษณะเสียงจาก Index ของชุดฝึก ค่าเพิ่มขึ้นอาจช่วยให้เสียงใกล้ชุดฝึก แต่ถ้าเสียงฝึกคุณภาพต่ำหรือมี Index ไม่เหมาะสม ผลลัพธ์อาจแย่ลง ให้เริ่มจากค่าเริ่มต้นแล้วเปรียบเทียบทีละระดับ

## 12. เลือก GPU สำหรับการแปลงเสียงอย่างไร

WebUI ใช้อุปกรณ์ตามค่าที่ตั้งใน `configs/config.py` รายชื่อการ์ดจอและหมายเลขอุปกรณ์ดูได้จากข้อมูลในแท็บ **ฝึกโมเดล**

## 13. ใช้โมเดลที่บันทึกไว้ระหว่างฝึกได้อย่างไร

เปิดแท็บ **จัดการโมเดล Checkpoint** เลือกไฟล์ Checkpoint ของการทดลอง แล้วสกัดออกมาเป็นโมเดล `.pth` ก่อนนำไปใช้แปลงเสียง

## 14. ฝึกแล้วเกิด Memory Error

ลองลดจำนวน CPU Threads ที่ใช้เตรียมข้อมูล และแบ่งเสียงฝึกให้เป็นไฟล์สั้นลง ปิดโปรแกรมอื่นที่ใช้หน่วยความจำมากก่อนเริ่มฝึก

## 15. เพิ่มข้อมูลแล้วฝึกต่อจากการทดลองเดิมอย่างไร

สร้างการทดลองใหม่และเตรียมชุดข้อมูล/คุณลักษณะเสียงให้ครบ จากนั้นคัดลอกไฟล์โมเดล Generator และ Discriminator ล่าสุดจากการทดลองเดิมไปยังโฟลเดอร์ทดลองใหม่ แล้วเลือกตัวเลือกฝึกต่อที่ตรงกับหน้า WebUI เวอร์ชันที่ใช้ ควรสำรองโฟลเดอร์เดิมก่อน

## 16. Windows แจ้งว่าไม่พบ `llvmlite.dll`

ติดตั้ง Microsoft Visual C++ Redistributable x64 จาก [เว็บไซต์ Microsoft](https://aka.ms/vs/17/release/vc_redist.x64.exe) แล้วเปิด Terminal และ WebUI ใหม่

## 17. พบ Tensor Error ขนาด `17280` กับ `0`

ตรวจไฟล์เสียงในชุดฝึก ลบหรือแยกไฟล์ที่สั้นผิดปกติหรือเสียหายออก แล้วลองประมวลผลข้อมูลและฝึกใหม่

## 18. ขนาด Tensor ไม่ตรงกัน เช่น `24` กับ `16`

อย่าเปลี่ยน Sample Rate ระหว่างฝึกการทดลองเดิม หากต้องการเปลี่ยน ให้สร้างชื่อการทดลองใหม่และเริ่มฝึกใหม่ โดยเตรียมข้อมูลและคุณลักษณะเสียงให้ตรงกับ Sample Rate นั้น
