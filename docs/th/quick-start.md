# คู่มือเริ่มใช้งาน RVC WebUI

RVC ใช้แปลงเสียงพูดหรือเสียงร้องที่มีอยู่แล้วให้เป็นโทนเสียงของโมเดลที่เลือก โปรแกรมนี้ **ไม่ได้แปลงข้อความเป็นเสียงพูด (Text-to-Speech)** โดยตรง

## ถ้าต้องการให้เสียงพูดตามสคริปต์

1. นำสคริปต์ไปสร้างเป็นไฟล์เสียงด้วยระบบ Text-to-Speech หรือบันทึกเสียงพูดเองก่อน
2. ในแท็บ **แปลงเสียง** เลือกโมเดลเสียงปลายทาง (`.pth`)
3. เลือกไฟล์เสียงสคริปต์ที่เตรียมไว้ในช่องอัปโหลด
4. เลือกอัลกอริทึม Pitch เช่น **RMVPE**; สำหรับเสียงพูดเริ่มจากค่า Pitch `0` ก่อน
5. กด **แปลงเสียง** แล้วฟังผลลัพธ์ หากพอใจให้ดาวน์โหลดจากเมนูจุดสามจุดของเครื่องเล่นเสียง

ต้องมีโมเดล `.pth` ใน `assets/weights/` ก่อน หากมีไฟล์ `.index` ของโมเดล ให้วางไว้ใน `assets/indices/` เพื่อช่วยให้โทนเสียงใกล้ชุดฝึกมากขึ้น

## ความหมายของตัวเลือกหลัก

- **ปรับ Pitch / เปลี่ยนระดับเสียง**: เพิ่มหรือลดระดับเสียงเป็นจำนวนครึ่งเสียง ค่า `12` คือสูงขึ้นหนึ่ง octave และ `-12` คือต่ำลงหนึ่ง octave
- **Pitch extraction algorithm**: วิธีตรวจจับระดับเสียงของต้นฉบับ สำหรับเสียงพูดทั่วไปลอง RMVPE หรือ PM
- **Index Rate**: เพิ่มสัดส่วนการใช้ดัชนีเสียงเพื่อให้ใกล้โทนชุดฝึกมากขึ้น ค่าสูงเกินไปอาจทำให้เสียงผิดเพี้ยน
- **Protect**: ช่วยรักษาเสียงพยัญชนะและเสียงหายใจ ลดเสียงแตกหรือเสียงสังเคราะห์ ค่าต่ำลงจะป้องกันมากขึ้น แต่อาจลดผลของ Index
- **Volume envelope**: ควบคุมว่าจะคงระดับความดังจากเสียงต้นฉบับหรือใช้ระดับความดังของเสียงที่แปลงแล้ว
- **Batch Inference**: ใช้แปลงไฟล์หลายไฟล์หรือทั้งโฟลเดอร์ และเลือกโฟลเดอร์บันทึกผลลัพธ์ได้

เริ่มปรับทีละค่า และเก็บเสียงต้นฉบับไว้เสมอ เพราะค่าที่เหมาะสมขึ้นกับเสียงพูด ไมโครโฟน และโมเดล

## ถ้าต้องการฝึกโมเดลเสียงของตัวเอง

1. เตรียมไฟล์เสียงพูดของผู้พูดคนเดียวที่ชัดเจน ไม่มีดนตรีหรือเสียงรบกวนมาก แนะนำให้มีข้อมูลเสียงสะอาดอย่างน้อยประมาณ 10 นาที
2. ในแท็บ **Train** ตั้งชื่อการทดลองและระบุโฟลเดอร์เสียงฝึก
3. ทำขั้นตอนเตรียมข้อมูลและตัดเสียง (Data slicing)
4. สกัด Pitch และคุณลักษณะเสียง (HuBERT feature extraction)
5. ตั้งค่าการฝึก แล้วเริ่มฝึกโมเดลและดัชนี
6. เมื่อฝึกเสร็จ นำโมเดล `.pth` ไปไว้ใน `assets/weights/` และไฟล์ `.index` ไปไว้ใน `assets/indices/` จากนั้นรีเฟรชรายการโมเดลเสียง

การฝึกต้องใช้ทรัพยากรเครื่องและอาจใช้เวลานาน ควรเริ่มจากชุดข้อมูลขนาดเล็กและตรวจสอบบันทึกการทำงานหากขั้นตอนไหนไม่สำเร็จ

## เปลี่ยนภาษาเมนู

เลือกภาษาในช่อง **Language / ภาษา** ด้านบน แล้วกด **Save language / บันทึกภาษา** จากนั้นปิด WebUI ด้วย `Ctrl+C` ในหน้าต่าง Terminal/Command Prompt แล้วเปิดใหม่ ภาษาไทยจะถูกเลือกอัตโนมัติได้เมื่อระบบปฏิบัติการตั้งค่าภาษาเป็นไทย หรือเลือกไทยจากช่องภาษาได้โดยตรง

## ข้อควรจำ

ใช้เสียงและโมเดลที่ได้รับอนุญาตจากเจ้าของเสียง และแจ้งผู้ฟังเมื่อเสียงที่เผยแพร่ผ่านการแปลงด้วย AI
