# คู่มือใช้งาน RVC WebUI: จากฝึกเสียงถึงพูดตามสคริปต์

ลำดับการใช้งานคือ **1) เตรียมโมเดลเสียงเป้าหมาย 2) สร้างเสียงจากสคริปต์ 3) แปลงเสียงด้วย RVC**
RVC เปลี่ยนโทนเสียงจากไฟล์เสียงที่มีอยู่แล้ว ไม่ได้อ่านข้อความแล้วพูดให้เอง

## 1. เตรียมหรือฝึกโมเดลเสียงเป้าหมาย

โปรเจ็กต์ **ไม่ได้แนบโมเดลเสียงตัวอย่าง `.pth`** สำหรับแปลงเสียงมาให้ หากมีโมเดล `.pth` ที่ได้รับอนุญาตอยู่แล้ว ให้นำไปใส่ใน `assets/weights/` แล้วข้ามไปขั้นตอนที่ 2 ได้เลย ไฟล์ `.index` ที่เข้าคู่กันเป็นไฟล์เสริม ให้วางใน `assets/indices/`

หากยังไม่มีโมเดลและต้องการฝึกเสียงของตัวเอง:

1. เตรียมไฟล์เสียงของผู้พูดเป้าหมายที่ชัดเจน ไม่มีดนตรีหรือเสียงรบกวนมาก ควรมีเสียงสะอาดประมาณ 10 นาทีขึ้นไป และมีสิทธิ์ใช้เสียงนั้น
2. เปิดแท็บ **ฝึกโมเดล** กรอก **ชื่อการทดลอง** และพาธโฟลเดอร์เสียงฝึก
3. ตรวจค่าการฝึก เช่น Sample Rate, รุ่นโมเดล และ F0 ให้ตรงกับชุดเสียง ตรวจว่ามีไฟล์โมเดลพื้นฐานใน `assets/pretrained/` หรือ `assets/pretrained_v2/` ตามที่หน้าจอกำหนด หากไม่มีให้ดาวน์โหลดตามหัวข้อโมเดลใน README
4. ตั้ง **บันทึกโมเดลขนาดเล็กลงในโฟลเดอร์ weights ทุกครั้งที่บันทึก** เป็น **ใช่** เพื่อให้ระบบบันทึกไฟล์โมเดลใช้งานระหว่างฝึก
5. กด **ฝึกโมเดลแบบขั้นตอนเดียว** ระบบจะเตรียม/ตัดข้อมูล สกัด Pitch และ HuBERT ฝึกโมเดล แล้วสร้าง Index ตามลำดับ รอจนสถานะแจ้งว่าเสร็จ
6. ตรวจว่ามีไฟล์ `.pth` ใน `assets/weights/` หากไม่มี ให้เปิดแท็บ **จัดการโมเดล Checkpoint** ใช้ส่วน **โมเดลสกัด** เลือก Checkpoint จาก `logs/<ชื่อการทดลอง>/` แล้วกด **แยกไฟล์** เพื่อสร้างโมเดลขนาดเล็ก

โมเดลฝึกพื้นฐานใน `assets/pretrained/` และ `assets/pretrained_v2/` ใช้ช่วยฝึก ไม่ใช่โมเดลเสียงบุคคลที่พร้อมนำไปแปลงเสียงทันที

## 2. สร้างไฟล์เสียงจากสคริปต์

นำข้อความไปสร้างเป็นไฟล์เสียงด้วยโปรแกรม Text-to-Speech (TTS) แยกต่างหาก หรืออัดเสียงพูดเอง แล้วบันทึกเป็น WAV หรือ MP3 เลือกเสียงต้นทางที่พูดชัดและไม่มีดนตรีดังรบกวน

## 3. แปลงเสียงตามสคริปต์ด้วยโมเดลเป้าหมาย

1. เปิดแท็บ **แปลงเสียง** แล้วเลือกแท็บย่อย **แปลงเสียงครั้งเดียว**
2. ที่ช่อง **เลือกโมเดลเสียงปลายทาง** เลือกไฟล์เสียงเป้าหมาย `.pth` หากเพิ่งฝึกเสร็จและไม่เห็นชื่อ ให้กด **รีเฟรชรายการโมเดลเสียง**
3. ที่ช่องอัปโหลดเสียง คลิก **Click to Upload** หรือลากไฟล์เสียงจากขั้นตอนที่ 2 ลงในกรอบ
4. เริ่มด้วยค่า Pitch `0` และเลือกวิธีตรวจจับ Pitch เป็น **RMVPE** สำหรับเสียงพูดทั่วไป
5. หากมีไฟล์ `.index` ตรวจช่องพาธไฟล์ดัชนีว่าเลือกไฟล์ของโมเดลเดียวกัน เริ่มจากค่า Index Rate ที่ระบบกำหนด
6. กด **แปลง** รอจนเสร็จ แล้วฟังเสียงในช่องผลลัพธ์ กดเมนูจุดสามจุดของเครื่องเล่นเพื่อดาวน์โหลด

ไฟล์ผลลัพธ์จะใช้คำพูดจากเสียงต้นทาง แต่เปลี่ยนโทนให้ใกล้กับโมเดลเป้าหมาย ถ้าต้องการแปลงหลายไฟล์ ให้ใช้แท็บย่อย **แปลงเสียงหลายไฟล์**

## ปรับคุณภาพหลังทดลองฟัง

- **Pitch**: ปรับระดับเสียงเป็นครึ่งเสียง ค่า `12` สูงขึ้นหนึ่ง octave และ `-12` ต่ำลงหนึ่ง octave
- **RMVPE**: วิธีตรวจจับระดับเสียง ลองใช้กับเสียงพูดทั่วไปก่อน
- **Index Rate**: เพิ่มการอ้างอิงโทนจากชุดฝึก ค่าเยอะขึ้นอาจช่วยให้ใกล้ชุดฝึก แต่ถ้ามากไปเสียงอาจผิดเพี้ยน
- **Protect**: ช่วยรักษาพยัญชนะและเสียงหายใจ ค่าต่ำลงคือป้องกันมากขึ้น
- **Volume envelope**: ปรับสัดส่วนความดังระหว่างเสียงต้นทางกับเสียงที่แปลง

ปรับทีละค่าและเก็บไฟล์ต้นฉบับไว้ เพราะค่าที่เหมาะสมขึ้นกับเสียงต้นทางและโมเดล

## แยกเสียงร้องหรือดนตรี

แท็บ **แยกเสียงร้อง/ดนตรี และลดเสียงก้อง** มีตัวเลือก PyMSS แต่ต้องมีไฟล์น้ำหนัก `.ckpt` ใน `assets/pymss_weights/` ด้วย ไฟล์ `.yaml` อย่างเดียวเป็นเพียงการตั้งค่าโมเดล หากติดตั้ง Hugging Face CLI แล้ว ดาวน์โหลดไฟล์ตามที่โครงการอ้างอิงจากโฟลเดอร์โปรเจ็กต์ได้ด้วย:

```bat
hf download lj1995/VoiceConversionWebUI --include "pymss_weights/*" --local-dir assets
```

## เปลี่ยนภาษาเมนู

เลือก **Language / ภาษา** ด้านบน กด **Save / บันทึก** แล้วหยุด WebUI ด้วย `Ctrl+C` ในหน้าต่าง Terminal/Command Prompt จากนั้นเปิด WebUI ใหม่ ภาษาไทยจึงจะมีผล

## คำถามที่พบบ่อย

เลือกแท็บ **คำถามที่พบบ่อย** ใน WebUI เพื่อดูวิธีแก้ปัญหาการฝึก การหาโมเดล และข้อผิดพลาดที่พบบ่อย

## ข้อควรจำ

ใช้เสียงและโมเดลที่ได้รับอนุญาตจากเจ้าของเสียง และแจ้งผู้ฟังเมื่อเผยแพร่เสียงที่ผ่านการแปลงด้วย AI
